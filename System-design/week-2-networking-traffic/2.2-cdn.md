# Content Delivery Network (CDN)

## What is it, in one line?

A **CDN** is a network of edge servers that cache content **near users** so downloads are faster and your origin handles less traffic.

---

## Why it exists

Light speed and geography matter: fetching a 2 MB image from Virginia to Mumbai adds **~150+ ms RTT** and congests long links. CDNs put copies in **Points of Presence (POPs)** worldwide.

**Real-world:** Netflix Open Connect places caches inside ISP networks; Spotify and news sites serve static assets from CloudFront/Fastly.

---

## Benefits (Primer)

1. Users get content from a **nearby** data center.
2. Your **origin** servers skip most static requests.

Typical CDN content: HTML/CSS/JS bundles, images, video segments. Some CDNs (CloudFront) also accelerate **dynamic** APIs with edge logic.

---

## Push vs pull CDNs

| | **Push CDN** | **Pull CDN** |
|--|--------------|--------------|
| **Who uploads** | You push files to CDN | CDN fetches from origin on first request |
| **Best for** | Low traffic, infrequent updates | High traffic, popular files |
| **Storage** | More on CDN | Less on CDN; may re-fetch if TTL expires |
| **URL** | You rewrite URLs to CDN domain | Same—rewrite to CDN |

**Pull flow:** First user in Tokyo requests `/logo.png` → CDN miss → origin fetch → cache at Tokyo POP → next users hit edge.

---

## TTL and staleness

**Time-to-live** controls how long edge serves a file without revalidating. Long TTL = fast but **stale** after deploy until purge or expiry.

**Real-world:** Deploy static JS with **content hash in filename** (`app.a1b2c3.js`) so CDN can cache “forever” safely.

---

## Disadvantages (Primer)

- **Cost** at high egress (weigh vs origin bandwidth).
- **Invalidation** complexity on emergency fix.
- Must **change URLs** or routing so clients hit CDN.

## Interview questions

- “When not use CDN?” — Mostly private API JSON with no cache headers; highly personalized responses.
- “Cache busting?” — Hashed filenames, purge API, short TTL on HTML entry.

---

## Recap

- CDN = geographic cache for static (often video) assets.
- **Push** vs **pull** by traffic and update pattern.
- Pair with DNS; mind TTL and deploy strategy.
