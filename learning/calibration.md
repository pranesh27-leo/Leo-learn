# Calibration — predicted vs actual

> **This is the most important file in the repo.** It is the evidence base that low confidence cannot argue with.
>
> **Two writes per problem.** Before you start: date, problem, predicted pattern, predicted minutes, confidence. After you finish: correct?, actual minutes, unaided?, error tag.
>
> **20 seconds each.** If it takes longer you are overthinking it.

## How to read this file later

- **Confidence 4–5 that ended unsolved** — the dangerous row. Flag every one. Overconfidence is the failure mode that gets you rejected.
- **Confidence 1–2 that you solved unaided** — the row that fixes your actual problem. Count these. When you have twenty, your self-model is provably wrong in your favour.
- **Predicted minutes vs actual, running ratio** — target within ±40%. Estimation accuracy is the single most senior-looking skill you have.
