# Dynamic Programming — 2D and Classics

Hello Algo **Ch 14.4–14.6**: knapsack, unbounded knapsack, edit distance.

## What is it, in one line?

**2D DP** uses a table `dp[i][j]` where each dimension represents a choice or a prefix. The recurrence fills the table cell by cell, and the answer is in a specific cell (usually the bottom-right corner).

---

## Why 2D?

1D DP has one axis (usually "first i items" or "first i positions"). 2D DP has **two** — typically comparing two sequences, or making two independent choices simultaneously.

| Problem | Dimension 1 | Dimension 2 |
|---------|------------|-------------|
| Edit distance | Prefix of string A | Prefix of string B |
| Longest common subsequence | Prefix of string A | Prefix of string B |
| 0/1 Knapsack | First i items | Remaining capacity w |
| Matrix path problems | Row index | Column index |

## Longest Common Subsequence (LC 1143)

**Problem:** Given `text1 = "abcde"` and `text2 = "ace"`, find the length of the longest subsequence common to both.

A **subsequence** is obtained by deleting zero or more characters (not necessarily contiguous). "ace" is a subsequence of "abcde."

### Defining the state

`dp[i][j]` = length of the LCS of `text1[0..i-1]` and `text2[0..j-1]`.

**In plain English:** "If I only look at the first i characters of text1 and the first j characters of text2, what's the longest common subsequence?"

### The recurrence

```
if text1[i-1] == text2[j-1]:
    dp[i][j] = 1 + dp[i-1][j-1]  // both characters match: extend the LCS
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  // skip one character from either string
```

### Implementation

```cpp
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0)); // base case: dp[0][*] = dp[*][0] = 0

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (text1[i-1] == text2[j-1])
                dp[i][j] = 1 + dp[i-1][j-1];
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);

    return dp[m][n];
}
```

### Tracing by hand

```
text1 = "abc", text2 = "ac"

       ""  a  c
    ""  0  0  0
    a   0  1  1    'a'=='a' → 1+dp[0][0] = 1
    b   0  1  1    'b'!='a' → max(dp[1][1], dp[2][0]) = 1
    c   0  1  2    'c'=='c' → 1+dp[2][1] = 2

LCS = 2 → "ac"
```

**Complexity:** O(m × n) time, O(m × n) space.

## Edit Distance (LC 72) — the same structure, different recurrence

**Problem:** Minimum number of operations (insert, delete, replace) to convert `word1` to `word2`.

### State

`dp[i][j]` = minimum edits to convert `word1[0..i-1]` to `word2[0..j-1]`.

### Recurrence

```
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]  // no operation needed
else:
    dp[i][j] = 1 + min(
        dp[i-1][j],    // delete word1[i-1]
        dp[i][j-1],    // insert word2[j-1]
        dp[i-1][j-1]   // replace word1[i-1] with word2[j-1]
    )
```

```cpp
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    // Base cases: converting to/from empty string
    for (int i = 0; i <= m; i++) dp[i][0] = i;  // delete all characters
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // insert all characters

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (word1[i-1] == word2[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});

    return dp[m][n];
}
```

### Tracing: "horse" → "ros"

```
     ""  r  o  s
  ""   0  1  2  3
  h    1  1  2  3    'h'!='r' → 1+min(1,1,0) = 1 (replace h→r)
  o    2  2  1  2    'o'=='o' → dp[1][1] = 1
  r    3  2  2  2    'r'=='r' → dp[2][0] = 2
  s    4  3  3  2    's'=='s' → dp[3][2] = 2

Edit distance = 2 (replace h→r, delete h)
```

**Complexity:** O(m × n) time, O(m × n) space.

## 0/1 Knapsack

**Problem:** Given items with weights and values, and a knapsack of capacity W, maximize total value. Each item can be taken at most once.

### State

`dp[w]` = maximum value achievable with exactly capacity w (or at most capacity w).

### Recurrence

For each item (weight `wt`, value `val`):
```
for w from W down to wt:  // descending! prevents using the same item twice
    dp[w] = max(dp[w], dp[w - wt] + val)
```

### Why iterate w descending?

If you iterate ascending, when you process item i at weight w, `dp[w - wt]` might already include item i (from a smaller weight in this same pass). That means you used the item twice. Descending prevents this: when you compute `dp[w]`, `dp[w - wt]` is from the previous iteration (item i hasn't been considered yet for smaller weights).

```cpp
int knapsack(int W, const vector<int>& weights, const vector<int>& values) {
    int n = weights.size();
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++)
        for (int w = W; w >= weights[i]; w--)
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i]);

    return dp[W];
}
```

**Complexity:** O(n × W) time, O(W) space (the 2D version uses O(n × W) space).

### Full 2D version (easier to understand)

```cpp
vector<vector<int>> dp(n + 1, vector<int>(W + 1, 0));
for (int i = 1; i <= n; i++)
    for (int w = 0; w <= W; w++)
        dp[i][w] = dp[i-1][w]; // don't take item i
        if (w >= weights[i-1])
            dp[i][w] = max(dp[i][w], dp[i-1][w - weights[i-1]] + values[i-1]); // take item i
```

Here `dp[i][w]` means "maximum value using first i items with capacity w." The answer is `dp[n][W]`.

## Unbounded Knapsack (Coin Change — LC 322)

**Difference:** Each item can be used **unlimited times**. Change the inner loop direction from **descending** to **ascending**:

```cpp
int coinChange(vector<int>& coins, int amount) {
    const int INF = amount + 1;
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;

    for (int c : coins)
        for (int a = c; a <= amount; a++)  // ascending! allows reusing the same coin
            dp[a] = min(dp[a], dp[a - c] + 1);

    return dp[amount] == INF ? -1 : dp[amount];
}
```

**Ascending vs Descending — the single most important distinction in knapsack DP:**

| Loop direction | Meaning | Use for… |
|---------------|---------|---------|
| **Descending** (W → wt) | Each item used at most once | 0/1 knapsack |
| **Ascending** (wt → W) | Each item used unlimited times | Unbounded knapsack, coin change |

## 2D DP — Matrix Path Problems

**Unique Paths (LC 62):** Given an m × n grid, find the number of unique paths from top-left to bottom-right, moving only right or down.

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]  // paths to (i,j) = paths from above + paths from left
```

```cpp
int uniquePaths(int m, int n) {
    vector<vector<int>> dp(m, vector<int>(n, 1)); // first row and first column all = 1
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
    return dp[m-1][n-1];
}
```

## The 2D DP Checklist

Every 2D DP problem follows these steps:

1. **Define the two dimensions** — what does `i` represent? What does `j` represent?
2. **Define `dp[i][j]` in plain English** — "what does this cell mean?"
3. **Base cases** — what is `dp[0][j]`? What is `dp[i][0]`?
4. **Recurrence** — how does `dp[i][j]` depend on earlier cells?
5. **Order of computation** — fill row by row, column by column, or diagonal?
6. **Answer location** — which cell contains the answer? Usually `dp[m][n]`.

---

## Common Mistakes

| Mistake | What happens | Fix |
|---------|-------------|-----|
| Off-by-one in indices | Wrong base case or access out of bounds | Use 1-indexed DP (size m+1 × n+1) with dp[0][*] as base case |
| Wrong loop direction in knapsack | Using item twice (ascending) or not using at all (descending for unbounded) | 0/1 = descending, unbounded = ascending |
| Not initializing base cases | dp[0][j] = 0 when it should be j (edit distance) | Think about the empty-string/empty-input case |
| Confusing subsequence with substring | LCS is for subsequence (non-contiguous); if you need substring, the recurrence changes | Subsequence: skip characters freely. Substring: require contiguous match |

---

## Recap

- **2D DP** = two dimensions, each representing a prefix or a choice. Table filled cell by cell.
- **LCS:** `dp[i][j]` = LCS of prefixes of length i and j. Match → diagonal + 1; mismatch → max(up, left).
- **Edit distance:** Same structure, three operations (insert, delete, replace).
- **0/1 Knapsack:** Descending inner loop. **Unbounded:** Ascending inner loop. This direction distinction is everything.
- **Matrix paths:** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`.
- **Always ask:** "In plain English, what does `dp[i][j]` mean?" If you can't answer in one sentence, you don't have the recurrence.
