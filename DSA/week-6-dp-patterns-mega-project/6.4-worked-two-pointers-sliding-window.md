# Worked Solution: Two Pointers and Sliding Window

## LC 3 — Longest Substring Without Repeating Characters

**Pattern:** Sliding window + last index map.

**Approach:** Maintain window `[start, i]` with all unique chars; when duplicate at `i`, move `start` past previous index of `s[i]`.

```cpp
int lengthOfLongestSubstring(string s) {
    vector<int> last(256, -1);
    int best = 0, start = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        unsigned char c = s[i];
        if (last[c] >= start) start = last[c] + 1;
        last[c] = i;
        best = max(best, i - start + 1);
    }
    return best;
}
```

**Time:** O(n). **Space:** O(1) fixed alphabet.

**Variant:** LC 424 (at most k replacements)—expand/shrink with frequency map.
