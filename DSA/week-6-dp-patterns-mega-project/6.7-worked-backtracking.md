# Worked Solution: Backtracking

## LC 46 — Permutations

**Pattern:** Backtracking with `used` array.

```cpp
void dfs(vector<int>& nums, vector<int>& cur, vector<int>& used, vector<vector<int>>& out) {
    if (cur.size() == nums.size()) { out.push_back(cur); return; }
    for (int i = 0; i < (int)nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = 1;
        cur.push_back(nums[i]);
        dfs(nums, cur, used, out);
        cur.pop_back();
        used[i] = 0;
    }
}

vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> out;
    vector<int> cur, used(nums.size(), 0);
    dfs(nums, cur, used, out);
    return out;
}
```

**Time:** O(n × n!). **Space:** O(n) recursion.
