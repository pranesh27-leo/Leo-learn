## Problem 1: Complexity classification

Classify time complexity:

```cpp
for (int i = 0; i < n; ++i)
    for (int j = i; j < n; ++j)
        ++count;
```

<details>
<summary>Solution</summary>

Inner loop runs about n-i times → total ~ n(n+1)/2 → **O(n²)**.

</details>

## Problem 2: Complexity classification

```cpp
int j = n;
while (j > 0) {
    j /= 2;
    ++count;
}
```

<details>
<summary>Solution</summary>

**O(log n)** — halving each iteration.

</details>

## Problem 3: Warmup — sum array (LC-style)

Given `vector<int> nums`, return sum. State complexity.

<details>
<summary>Solution</summary>

```cpp
long long sumArray(const vector<int>& nums) {
    long long s = 0;
    for (int x : nums) s += x;
    return s;
}
```

**O(n)** time, **O(1)** extra space.

</details>
