# Binary Search Tree (BST)

## What is it, in one line?

For every node: **left subtree < node < right subtree**—enables O(log n) search when balanced.

Hello Algo **Ch 7.4**: [Binary search tree](https://www.hello-algo.com/en/chapter_tree/binary_search_tree/).

---

## Search

```cpp
TreeNode* searchBST(TreeNode* root, int target) {
    while (root) {
        if (target == root->val) return root;
        root = target < root->val ? root->left : root->right;
    }
    return nullptr;
}
```

## Validate BST (LC 98)

Pass min/max bounds down:

```cpp
bool validate(TreeNode* node, long long lo, long long hi) {
    if (!node) return true;
    if (node->val <= lo || node->val >= hi) return false;
    return validate(node->left, lo, node->val) &&
           validate(node->right, node->val, hi);
}
bool isValidBST(TreeNode* root) {
    return validate(root, LLONG_MIN, LLONG_MAX);
}
```
