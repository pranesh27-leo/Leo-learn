# Binary Search Patterns

## What is it, in one line?

Repeatedly halve the search space on **sorted** data or **answer space** where monotonicity holds.

Hello Algo **Ch 10**: [Binary search](https://www.hello-algo.com/en/chapter_searching/binary_search/).

---

## Classic search

```cpp
int binarySearch(const vector<int>& a, int target) {
    int lo = 0, hi = (int)a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

O(log n).

## Search rotated sorted array (LC 33)

One half is always sorted—decide which half to keep. Pattern: **modified binary search**.

## Binary search on answer
