# Iteration and Recursion

## What is it, in one line?

**Iteration** uses loops; **recursion** solves a problem by solving smaller instances of the same problem until a **base case**.

Hello Algo **Chapter 2.2**: [Iteration and recursion](https://www.hello-algo.com/en/chapter_computational_complexity/iteration_and_recursion/).

---

## Why it exists

Trees, graphs, backtracking, and divide-and-conquer are natural in recursion. Loops often save stack space.

---

## Recursion template

```cpp
int dfs(int state) {
    if (base_case) return base_value;
    // combine results from recursive calls
    return dfs(smaller_state);
}
```

---

## Example: factorial

```cpp
long long fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```

Time O(n), stack O(n)—iterative version uses O(1) stack.

---

## When recursion shines

- Tree traversals (pre/in/post order)
- Merge sort, quick sort partitions
- Backtracking (Week 5)

---

## Tail recursion note

Some compilers optimize tail calls; do not rely on it in interviews—mention stack depth for large n.
