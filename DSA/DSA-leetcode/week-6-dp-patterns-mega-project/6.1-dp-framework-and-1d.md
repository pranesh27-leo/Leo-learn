# Dynamic Programming — Framework and 1D DP

Hello Algo **Ch 14**: [Intro to DP](https://www.hello-algo.com/en/chapter_dynamic_programming/intro_to_dynamic_programming/).

## When DP applies

1. **Optimal substructure** — optimal solution built from optimal subsolutions.
2. **Overlapping subproblems** — same subproblem reused (memoize or tabulate).

## Steps

1. Define state `dp[i]` meaning.
2. Recurrence relation.
3. Base cases.
4. Order of computation (bottom-up) or memo (top-down).

## Climbing stairs (LC 70)

`dp[i] = dp[i-1] + dp[i-2]` → Fibonacci. O(n) time, O(1) space with two vars.

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; ++i) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```
