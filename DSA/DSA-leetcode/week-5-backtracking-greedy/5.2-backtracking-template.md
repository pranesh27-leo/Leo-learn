# Backtracking Template

Hello Algo **Ch 13**: [Backtracking](https://www.hello-algo.com/en/chapter_backtracking/backtracking_algorithm/).

## Template

```cpp
void backtrack(state, choices) {
    if (complete(state)) { record; return; }
    for (choice : choices) {
        if (!valid(choice)) continue;
        apply(choice);
        backtrack(state, next_choices);
        undo(choice);  // restore
    }
}
```

## Permutations (LC 46)
