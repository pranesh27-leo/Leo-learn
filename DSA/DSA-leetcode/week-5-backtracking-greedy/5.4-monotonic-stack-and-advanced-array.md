# Monotonic Stack

## What is it, in one line?

Stack keeping elements in **monotonic** (increasing/decreasing) order—answers **next greater element** in O(n).

## Daily temperatures (LC 739)

Stack stores indices; pop when current temp warmer.

```cpp
vector<int> dailyTemperatures(vector<int>& t) {
    int n = (int)t.size();
    vector<int> ans(n, 0);
    stack<int> st;
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && t[i] > t[st.top()]) {
            int j = st.top(); st.pop();
            ans[j] = i - j;
        }
        st.push(i);
    }
    return ans;
}
```

Leetcode Patterns: **next greater/smaller** signal.
