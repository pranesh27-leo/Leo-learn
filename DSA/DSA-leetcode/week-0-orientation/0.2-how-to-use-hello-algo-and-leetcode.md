# How to Use Hello Algo + LeetCode Together

## What is it, in one line?

**Hello Algo** teaches *what* each structure is and *how* it works; **LeetCode + Patterns** teaches *when* to recognize and apply them under time pressure.

---

## Why it exists

Reading without coding feels easy; grinding without theory feels random. This course enforces a **loop**: learn → implement → pattern-drill.

---

## Recommended loop (per topic)

1. Read the **week lesson** in this repo (30–45 min).
2. Open the matching **Hello Algo EN chapter** for diagrams and intuition.
3. Run **Hello Algo C++** for that chapter ([github.com/krahets/hello-algo/tree/main/codes/cpp](https://github.com/krahets/hello-algo/tree/main/codes/cpp)).
4. Solve **2–4** problems from this week’s practice file.
5. On [Leetcode Patterns](https://seanprashad.com/leetcode-patterns/), filter by the same pattern name and do **one more** problem.

## LeetCode setup tips

- Use **C++** template you are comfortable with (`vector`, `unordered_map`, `queue`).
- After pass: write **time/space** in comment and **pattern name**.
- Keep a **mistake log**: problem → wrong approach → correct pattern.
