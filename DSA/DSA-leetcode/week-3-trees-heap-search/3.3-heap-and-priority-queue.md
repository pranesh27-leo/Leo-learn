# Heap and Priority Queue

## What is it, in one line?

A **min-heap** keeps the smallest element at the root; insert/extract-min in O(log n).

Hello Algo **Ch 8**: [Heap](https://www.hello-algo.com/en/chapter_heap/heap/), [Top-k](https://www.hello-algo.com/en/chapter_heap/top_k/).

C++: `priority_queue<int>` is **max-heap** by default; use `priority_queue<int, vector<int>, greater<int>>` for min-heap.

---

## Kth largest element (LC 215)

Maintain min-heap of size k:

```cpp
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int x : nums) {
        pq.push(x);
        if ((int)pq.size() > k) pq.pop();
    }
    return pq.top();
}
```

O(n log k) time.
