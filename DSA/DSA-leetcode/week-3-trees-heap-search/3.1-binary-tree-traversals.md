# Binary Tree Traversals

## What is it, in one line?

Visit every node in a defined order: **preorder** (root-left-right), **inorder** (left-root-right), **postorder** (left-right-root), or **level-order** (BFS).

Hello Algo **Ch 7**: [Binary tree traversal](https://www.hello-algo.com/en/chapter_tree/binary_tree_traversal/).

---

## TreeNode (LeetCode style)

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

---

## DFS inorder (recursive)

```cpp
void inorder(TreeNode* root, vector<int>& out) {
    if (!root) return;
    inorder(root->left, out);
    out.push_back(root->val);
    inorder(root->right, out);
}
```

Inorder on BST → **sorted order**.
