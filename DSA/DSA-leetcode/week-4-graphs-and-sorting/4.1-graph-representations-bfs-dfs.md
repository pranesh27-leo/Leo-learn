# Graph Representations, BFS, and DFS

Hello Algo **Ch 9**: [Graph](https://www.hello-algo.com/en/chapter_graph/graph/), [Graph traversal](https://www.hello-algo.com/en/chapter_graph/graph_traversal/).

## Representations

- **Adjacency list:** `vector<vector<int>> g(n)` — common for sparse graphs.
- **Adjacency matrix:** O(1) edge check, O(n²) memory.

## BFS — shortest steps in unweighted graph

```cpp
int bfsDist(int start, int end, const vector<vector<int>>& g) {
    queue<int> q;
    vector<int> dist(g.size(), -1);
    q.push(start);
    dist[start] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (u == end) return dist[u];
        for (int v : g[u])
            if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
    return -1;
}
```
