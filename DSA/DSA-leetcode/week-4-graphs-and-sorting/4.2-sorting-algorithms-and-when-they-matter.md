# Sorting Algorithms (Interview Focus)

Hello Algo **Ch 11**: [Sorting](https://www.hello-algo.com/en/chapter_sorting/sorting_algorithm/).

| Algorithm | Time avg | Space | Notes |
|-----------|----------|-------|-------|
| Quick sort | O(n log n) | O(log n) stack | `std::sort` |
| Merge sort | O(n log n) | O(n) | Stable |
| Heap sort | O(n log n) | O(1) | |
| Counting sort | O(n+k) | O(k) | Small integer range |

**Interview:** know **when sorting helps** (intervals, two-sum with duplicates strategy, merge k lists) more than implementing radix sort from scratch.

Use `#include <algorithm>` `sort(v.begin(), v.end())` in C++.
