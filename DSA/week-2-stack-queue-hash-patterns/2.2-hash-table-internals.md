# Hash Table Internals

## What is it, in one line?

A **hash table** maps keys to buckets via a **hash function**; collisions handled by chaining or open addressing.

Hello Algo **Chapter 6**: [Hash map](https://www.hello-algo.com/en/chapter_hashing/hash_map/), [Hash collision](https://www.hello-algo.com/en/chapter_hashing/hash_collision/).

---

## Why it exists

Average **O(1)** insert/lookup/delete—compilers, databases, caches, Two Sum problems.

C++: `std::unordered_map`, `std::unordered_set`.

---

## Collision strategies

| Method | Idea |
|--------|------|
| **Chaining** | Bucket = list of entries |
| **Open addressing** | Probe next slot |

Load factor high → rehash to larger table.

---

## Two Sum (LC 1) — canonical hash pattern

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int,int> pos;
    for (int i = 0; i < (int)nums.size(); ++i) {
        int need = target - nums[i];
        if (pos.count(need)) return {pos[need], i};
        pos[nums[i]] = i;
    }
    return {};
}
```
