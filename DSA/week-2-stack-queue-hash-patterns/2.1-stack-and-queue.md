# Stack and Queue

## What is it, in one line?

**Stack** = LIFO (last in, first out); **Queue** = FIFO (first in, first out).

Hello Algo **Chapter 5**: [Stack](https://www.hello-algo.com/en/chapter_stack_and_queue/stack/), [Queue](https://www.hello-algo.com/en/chapter_stack_and_queue/queue/).

---

## Why it exists

- **Stack:** undo, parentheses matching, DFS iterative, expression evaluation.
- **Queue:** BFS, task scheduling, buffering.

C++: `std::stack`, `std::queue`, `std::deque` (double-ended queue).

## Valid parentheses (LC 20)

```cpp
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '{' || c == '[') st.push(c);
        else {
            if (st.empty()) return false;
            char o = st.top(); st.pop();
            if ((c==')' && o!='(') || (c==']' && o!='[') || (c=='}' && o!='{'))
                return false;
        }
    }
    return st.empty();
}
```

O(n) time, O(n) space.
