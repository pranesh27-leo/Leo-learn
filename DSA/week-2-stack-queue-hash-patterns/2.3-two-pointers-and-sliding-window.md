# Two Pointers and Sliding Window

## What is it, in one line?

**Two pointers** move across a sequence; **sliding window** maintains a contiguous subarray/substring with an **invariant**.

Leetcode Patterns: core array/string techniques.

---

## Two pointers on sorted array

Pair with sum `target`: `l=0`, `r=n-1`; if sum too small, `++l`; else `--r`. O(n).

---

## Sliding window template (variable size)

```cpp
int longestUniqueSubstring(const string& s) {
    vector<int> last(256, -1);
    int best = 0, start = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        if (last[(unsigned char)s[i]] >= start)
            start = last[(unsigned char)s[i]] + 1;
        last[(unsigned char)s[i]] = i;
        best = max(best, i - start + 1);
    }
    return best;
}
```

LC 3 — longest substring without repeating characters. O(n).

---

## Fixed window size k

Max sum subarray of size k: slide window, add incoming, subtract outgoing.

---

## When to use (heuristic)

| Signal | Pattern |
|--------|---------|
| Sorted array, pair/triplet | Two pointers |
| Substring/subarray optima | Sliding window |
| In-place O(1) space | Two pointers write index |
