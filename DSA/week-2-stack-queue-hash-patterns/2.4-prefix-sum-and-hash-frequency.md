# Prefix Sum and Hash Frequency

## What is it, in one line?

**Prefix sum** precomputes cumulative totals for O(1) range queries; **frequency maps** count occurrences for anagrams and subarray sum problems.

---

## Prefix sum

`pref[0]=0`, `pref[i+1]=pref[i]+nums[i]`. Sum of `nums[l..r]` = `pref[r+1]-pref[l]`.

---

## Subarray sum equals K (LC 560)

Count subarrays with sum k using prefix + hash of prefix counts:

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<long long,int> cnt;
    cnt[0] = 1;
    long long pref = 0, ans = 0;
    for (int x : nums) {
        pref += x;
        ans += cnt[pref - k];
        ++cnt[pref];
    }
    return ans;
}
```

O(n) time, O(n) space.
