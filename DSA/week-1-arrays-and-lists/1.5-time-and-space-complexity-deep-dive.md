# Time and Space Complexity — Deep Dive

## What is it, in one line?

Analyze **worst-case** growth of time and auxiliary memory as `n` → large, using Big-O notation.

Hello Algo **Ch 2.3–2.4**: [Time complexity](https://www.hello-algo.com/en/chapter_computational_complexity/time_complexity/), [Space complexity](https://www.hello-algo.com/en/chapter_computational_complexity/space_complexity/).

## Why it exists

Interviewers reject O(n²) when n ≤ 10^5 if O(n) exists.

---

## Analyzing nested code

```cpp
for (int i = 0; i < n; ++i)
    for (int j = 0; j < n; ++j)
        work(); // O(1)
```

→ **O(n²)**.

```cpp
for (int i = 0; i < n; ++i)
    for (int j = 0; j < i; ++j)
        work();
```

Still **O(n²)** (sum 0+1+…+n-1).

---

## Amortized analysis (vector push_back)

Doubling capacity when full → average **O(1)** per push over sequence.

---

## Master theorem (sketch)

For divide-and-conquer `T(n) = aT(n/b) + O(n^d)`:

- Merge sort: a=2, b=2, d=1 → **O(n log n)**.

Use when you split problem in half each level.

---

## Space: recursion tree

Merge sort: tree depth log n, each level O(n) temporary → **O(n)** extra space (typical implementation).

---

## Interview script

“Time O(n) single pass; space O(k) for hash map of at most k keys.”
