## LC 27 — Remove Element

**Pattern:** In-place two-pointer / write index.

<details>
<summary>C++ solution</summary>

```cpp
int removeElement(vector<int>& nums, int val) {
    int k = 0;
    for (int x : nums)
        if (x != val) nums[k++] = x;
    return k;
}
```

O(n), O(1).

</details>

## LC 21 — Merge Two Sorted Lists

**Pattern:** Linked list dummy head.

<details>
<summary>C++ solution</summary>

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (l1 && l2) {
        if (l1->val <= l2->val) { tail->next = l1; l1 = l1->next; }
        else { tail->next = l2; l2 = l2->next; }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}
```

O(n+m), O(1).

</details>

Merge `nums2` into `nums1` from the **end** to avoid overwrite.

<details>
<summary>Approach</summary>

Three pointers: i = m+n-1, p1 = m-1, p2 = n-1; place larger at i--. O(m+n), O(1).
