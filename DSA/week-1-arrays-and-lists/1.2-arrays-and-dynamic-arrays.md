# Arrays and Dynamic Arrays

## What is it, in one line?

An **array** stores elements in **contiguous memory**; C++ `std::vector` is a **dynamic array** that grows amortized O(1) at the end.

---

## Why it exists

**Cache locality:** sequential access is fast—CPUs prefetch nearby cells. Real-world: image rows, audio samples, embedding vectors.

---

## Core operations

| Op | Time |
|----|------|
| Index `a[i]` | O(1) |
| Push back (vector) | O(1) amortized |
| Insert/delete middle | O(n) — shift elements |

---

## In-place removal pattern (LC 27)

Remove all val in-place, return new length:

```cpp
int removeElement(vector<int>& nums, int val) {
    int k = 0;
    for (int x : nums)
        if (x != val) nums[k++] = x;
    return k;
}
```

**Invariant:** `nums[0..k-1]` holds kept elements. O(n) time, O(1) space.
